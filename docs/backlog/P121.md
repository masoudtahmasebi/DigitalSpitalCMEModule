# P121 — No screen could say whether this installation files Punktemeldungen

**Status:** built (`a620736`). One screen, one banner, and a question that was
previously answerable only by reading `config.env` on the host.

---

## The gap

EIV submission is governed by two independent settings — whether the worker runs
at all, and which endpoint tier it is pointed at. Both live in the deployment,
neither was rendered anywhere, and the difference between them is the difference
between a test that is safe and a test that files a statutory Punktemeldung
against a real physician's EFN at a real Ärztekammer.

So the only way to answer "will this server file anything?" was to have a shell
on it. That is §9.10: a refusal (or in this case a silence) that is correct and
unhelpful, where the answer belongs in front of the audience already entitled to
it. Here that audience is an operator on the Punktemeldungen screen.

It is also §9.9 in its usual form. The repository's state is not the
installation's state, and nothing on the installation said which state it was in.

## What was built

`reportingPosture()` in `eiv-admin.service.ts`, and a banner at the top of
**Verwaltung → Teilnahme → Punktemeldungen** that renders its answer.

```ts
willFile: this.options.submissionsEnabled && (tier === "live" || tier === "test"),
```

Both halves are required, because either one alone is a half-truth: a worker
that is enabled but pointed at a local mock files nothing, and a live tier with
the worker disabled files nothing either. A banner reporting one of the two
would be §9.10a — a setting whose comment names one of its consequences.

## Why it matters beyond the console

It became the **gate on the whole test pack**. DEP-5 opens by telling the tester
to read this banner and stop if it does not say `Meldungen werden nicht
übermittelt` — because the pack is run against **ADHS Akademie adult**, which
carries the real VNR `2760552025919300018` from the ÄKWL Anerkennungsbescheid,
and a filed Punktemeldung cannot be unfiled, only withdrawn, which leaves its
own record.

A test pack whose first instruction is "read the screen that tells you whether
this is safe" is only possible because the screen now exists.

## Not done

- `EIV_WORKER_ENABLED=no` on the production host is a change to `config.env`,
  which is the client's to make. The banner reports the posture; it does not set
  it.
