## P245-01 — two Superpowers skills, adapted to the backlog

**Review gate:** none — development tooling; no `apps/` change.

**Context**

The recurring cost the article names — a session that builds the wrong thing
and then argues its way back — is the one CLAUDE.md §3 prices highest here,
because every feature has to keep working under tenant isolation and
compliance. Superpowers' `brainstorming` puts a hard approval gate and one
question at a time in front of any code; `writing-plans` turns the agreed
design into steps with a test per step.

Rejected: installing the plugin. Its `SessionStart` hook injects an instruction
to invoke skills before any response, on every session — a second rulebook over
CLAUDE.md. Details in `.claude/skills/THIRD-PARTY.md`.

**Scope**

- `.claude/skills/brainstorming/` and `.claude/skills/writing-plans/`, adapted:
  explicit invocation only; output is a ticket in `docs/backlog/`, not a
  `docs/superpowers/` file; the CLAUDE.md checks that can stop a design (§2, §3,
  §4, §7, §9) run inside it; commits use the `P`-number format; each plan step
  is broken on purpose before it is committed.
- Upstream licence and the change log kept beside them.

**Acceptance criteria**

- [x] Neither skill loads itself: both carry `disable-model-invocation: true`.
- [x] No hook, script, server or other skill from Superpowers is in the
      repository.
- [x] Every command and path the two skills name exists. Verified: the root
      `package.json` scripts, `@ds/domain` and `@ds/api` `test` scripts,
      `apps/widget/src/locale/`, `docs/show-stoppers.md`,
      `scripts/verify-loop.sh`.
- [x] `pnpm format`, `pnpm lint`, `pnpm check:backlog` and `pnpm check:static`
      pass.

**Not in scope**

Using the skills on a real ticket. The first ticket written through
`/brainstorming` is the test of whether this was worth it.
