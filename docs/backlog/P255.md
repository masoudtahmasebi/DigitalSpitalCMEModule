## P255-01 — band sized to what it carries; room under the last button

**Review gate:** none · learner-facing presentation only

**Top.** The mobile hero band was `h-[27.5rem]` (440 px) whether or not a
catalogue photograph is set. The installation has none, so the phone opened on
plain teal with the seal in its bottom-left corner and **224 px** of empty band
above it (440 − 40 `bottom-10` − 176 seal). Without a photograph the band is now
`h-64` (256 px = 40 + 176 + 40). With a photograph it is unchanged, as drawn.

**Bottom.** Below `sm`, `TabbedPanel`'s button row is the last thing the widget
draws and nothing followed it, so "Weitere" stood **0 px** from the host's lower
edge — on the theme footer. `max-sm:pb-10` on `TabbedPanel`, which fixes all
three callers (catalogue, course detail, preview) at once.

Verified: `katalog-abstaende.spec.ts`, at 390 × 844 against the e2e stack —

| state                  | empty above seal | below last button |
| ---------------------- | ---------------- | ----------------- |
| before                 | 224 (red)        | —                 |
| after, `pb-10` removed | —                | 0 (red)           |
| after                  | ≤ 48 (green)     | ≥ 32 (green)      |

Full `pnpm test:e2e`: 40 passed. Widget unit tests: 463 passed.

Not verified: the installation itself until the deploy of this commit has run.

**Acceptance criteria**

- [x] No empty band above the seal when no photograph is set.
- [x] Space under the last button inside the widget's own box, on every screen
      that uses `TabbedPanel`.
- [x] A browser test that went red on each half before the fix.
- [ ] Seen on MEDICE's page after deploy.

If MEDICE uploads a catalogue photograph (Verwaltung → Organisation), the band
returns to 27.5 rem — that is the drawn layout for a band with an image.

## P255-02 — a unit test with an expiry date

**Review gate:** none · test fixture only

CI on `main` was red from `d08d573` on, in `@ds/api#test`, unrelated to either
change: 11 `catalog.service.test.ts` cases answered
`course slug=adhs-akademie-adult is not offered: ended`. The fixture's
`validTo` is `2026-10-12T23:59:59Z` and the service defaults to the wall
clock, so the tests began failing on 13.10.2026 on every commit — and a red CI
on `main` means no deploy.

Every `CatalogService` in the file now reads one fixed clock, `AT`
(01.06.2026), inside the fixture's window. Verified: 26 passed; with `AT` set to
14.10.2026, 11 failed — the original failure, reproduced on purpose. Workspace
`pnpm test`: 30 of 30 tasks.

Not done: a sweep for other fixtures that pass only because of today's date.
