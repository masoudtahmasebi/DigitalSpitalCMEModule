## P255-01 — band sized to what it carries; room under the last button

**Review gate:** none · learner-facing presentation only

**Top.** The mobile hero band was `h-[27.5rem]` (440 px) whether or not a
catalogue photograph is set. The installation has none, so the phone opened on
plain teal with the seal in its bottom-left corner and **224 px** of empty band
above it (440 − 40 `bottom-10` − 176 seal). Without a photograph the band is now
`h-64` (256 px = 40 + 176 + 40). With a photograph it is unchanged, as drawn.

**Bottom.** Below `sm`, `TabbedPanel`'s button row is the last thing the widget
draws and nothing followed it, so "Weitere" stood **0 px** from the host's lower
edge — on the theme footer. `max-sm:pb-10` on `TabbedPanel`, which fixes all
three callers (catalogue, course detail, preview) at once.

Verified: `katalog-abstaende.spec.ts`, at 390 × 844 against the e2e stack —

| state                  | empty above seal | below last button |
| ---------------------- | ---------------- | ----------------- |
| before                 | 224 (red)        | —                 |
| after, `pb-10` removed | —                | 0 (red)           |
| after                  | ≤ 48 (green)     | ≥ 32 (green)      |

Full `pnpm test:e2e`: 40 passed. Widget unit tests: 463 passed.
