# P75 — a length nobody can type wrong

Reported 14.08, from the MEDICE course on production:

> _"let's remove the hand typing of video length completely, is it is
> completely based on the automatic length calculation, because now in the
> course i have a video which is 45 seconds and the system says you have to
> watch a video for 25 minutes, which there is not, and i can not go further in
> the course"_

---

## Why this was not a cosmetic bug

The watch gate is a percentage of `durationSec`. A figure **larger than the
file** is therefore not an inaccuracy — it is a module nobody can finish,
because the seconds it demands do not exist to be watched. The learner sees a
progress bar that cannot fill, a countdown that cannot reach zero, and no
sentence anywhere explaining why. `0 % der Fortbildung absolviert` after
watching the whole video.

The instance: `packages/seed/src/medice-adhs.ts` writes `durationSec: 1524` for
Modul 1 — a figure taken from the layout, describing no file the seed ships,
because the seeded video URLs are placeholders on a domain nobody owns (P72).
Somebody attached a real 45-second recording through the console, and the
seeded 1524 stayed behind.

## P75-01 · the file decides, and the field is gone

The form had a number input with "Aus Video ermitteln" beside it. The
measurement was **offered**, on the reasoning that an author might have a
deliberate figure — a recording with thirty seconds of black at the end, or a
length agreed with the Ärztekammer.

That reasoning was wrong in the direction that matters. A field an author _can_
get wrong is one that eventually is wrong; nothing downstream can tell; and the
person who pays is a physician who cannot complete their Fortbildung.

So `MeasuredDuration` reads the file when the source changes and renders the
result as what it is — `0:45 (45 Sekunden)`, not an editable box. Changing the
video now changes the length with it, which is precisely what did not happen on
the reported course.

### The one escape hatch, and why it stays

A length that cannot be measured must not make the content unsaveable. A
customer's own CDN may send no CORS headers; an adaptive manifest may report
nothing. In exactly that case the field becomes editable and says why, and the
hint names the consequence rather than just asking for a number:

> Eine zu große Zahl macht den Abschnitt unabschließbar, weil die geforderten
> Sekunden im Video nicht existieren.

Removing it outright would replace "a wrong number" with "a course that cannot
be authored at all". That is CLAUDE.md §9.2 read in both directions: a control
that can only produce an error is worse than none — and so is an absent control
that was the only way through.

### What the journey now proves

The assertion has moved twice, and the history is the point:

|               |                                                                                       |
| ------------- | ------------------------------------------------------------------------------------- |
| before P74-04 | `fill("18")` — a hard-coded number that would stay green through any regression       |
| P74-04        | click "Aus Video ermitteln", assert the value                                         |
| P75-01        | **nothing is clicked**; the form measures by itself and the run waits for the reading |

It still walks the whole chain in one act — the API mints a read signature, the
bucket's CORS rule allows `GET`, the CSP permits the load, the browser decodes
the header — and not one of those four is visible to an API test. Red-checked by
inverting the effect's guard: the journey fails with the diagnostic naming all
four causes in order.

### Acceptance criteria

- [x] No number field for a video whose length can be measured
- [x] The measurement runs on its own when the source changes, keyed on the URL
      so a keystroke in a label does not re-probe a lecture
- [x] A length that cannot be read leaves an editable field that says why
- [x] The journey asserts the measured value with no click and no fallback
- [x] Red-checked

## Deliberately not done

**Deleting the fabricated durations from the MEDICE seed.** A video content
must carry a positive `durationSec` — `contentProblems` in `@ds/domain` refuses
otherwise — so writing `null` would make the seeded course unpublishable, and
the seed's real problem is that it ships no media at all. That is P72, which now
records the duration half explicitly: a fake URL is visible the moment somebody
presses play; a fake duration is invisible until a physician is stuck behind it.
The seed carries a comment naming this incident so the next person adding a
module does not add a plausible number beside media that does not exist.

**Letting the learner's browser correct the gate.** The widget knows the file's
real length once metadata loads, and it must not be allowed to decide anything
that affects a CME point (CLAUDE.md §4 invariant 1). Reporting the disagreement
— to the learner, who is stuck, and to the operator, who can fix it — is worth
doing and is its own ticket.

## Still open

**A learner facing a misconfigured length is told nothing.** After this change
no new course can acquire a wrong length through the console, and every existing
one still can have one. The player should say "dieser Abschnitt ist fehlerhaft
konfiguriert" rather than showing a bar that cannot fill, and `MediaCheck`
should report the disagreement to the operator — the audience already entitled
to the answer (§9.10).
