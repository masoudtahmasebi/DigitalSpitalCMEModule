## 4. What I found running the cases against the code

Three defects. Two fixed in `f3e7a31`, one class of problem now has a check.

### DEP-14 T09.4 — the Mediathek had no address · **fixed**

**How I tested it.** Read `apps/widget/src/route.ts`: the fragment grammar knew
`outline`, `content`, `evaluation`, `reporting` and no tab. Then
`apps/widget/src/App.tsx:395` — `const [tab, setTab] = useState<Tab>("overview")`,
never read from or written to the URL.

**What was wrong.** Four screens a physician can stand in — Übersicht,
Referenten, **Mediathek**, Zertifizierung — with no address between them. All
three symptoms at once: reload dropped you back to Übersicht, Back left the
course, and "look at the Mediathek" was a screenshot instead of a link.

**Fixed.** `#ds/mediathek`, `#ds/referenten`, `#ds/zertifizierung` now work in
both directions. `#ds` still means Übersicht so older links keep resolving.

**Re-test in the browser (this is DEP-14 T09.4, and please still run it):** open
the Mediathek, reload — you should stay on it. Then press Back — you should land
on Übersicht, not leave the course.

### DEP-15 T10.4 — a disabled button that never said why · **fixed**

**How I tested it.** `CompletionScreen.tsx:140` — `ready` requires
`(!consentAvailable || consented)`. Then searched the file for the sentence that
explains it: nothing rendered `de.completion.consentRequired`, which had been
written for exactly this.

**What was wrong.** Leave the consent box unticked and **Fortbildung abschließen**
is dead, with no explanation anywhere on the screen. §9.4.

**Fixed.** The sentence now appears once the name fields are filled — not from
the start, because an instruction that is true too early reads as an error about
a field you have not reached yet.

### 19 sentences that no screen draws · **check added, 4 raised**

`check:i18n` counts whether a German string has an English counterpart. It is
completely satisfied by a sentence nothing renders, so 19 of 291 were dead and no
gate said so. `scripts/copy-coverage.mjs` now catches that, in `pnpm verify`.

**Four are real gaps and the wording is not mine to invent** — they need a
decision from MEDICE or from Philipp:

| String                           | The gap                                                                                                     |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `signedOut.expiredTitle/Message` | nothing distinguishes a session that expired mid-course from a token that never arrived                     |
| `gate.lockedHint`                | a locked section says _Gesperrt_ and does not say what opens it — **this is DEP-13 T08.1 and DEP-19 T14.4** |
| `content.videoUnsupported`       | a browser that cannot play the video says nothing — **this is DEP-20 T15.1**                                |
| `quiz.claimWithoutPoints`        | a nought-point course still offers "CME-Punkte geltend machen"                                              |

**One deserves naming as a non-finding**, because it is what §9.3 warns about:
`player.examInModule` was written so three identically-named Lernerfolgskontrolle
rows could be told apart. The sidebar already nests each exam under its module,
so the ambiguity does not arise, and wiring the string would have invented a
screen. A dead string is not automatically a bug — somebody has to look.
