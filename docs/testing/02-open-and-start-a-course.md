# 02 · Opening and starting a course

**Assignee: Philipp Burka**
**Area:** Participant portal · **Duration:** approx. 25 minutes

## Goal

Check that a course's detail page explains fully what you are committing to
before you begin.

## Prerequisites

- Signed in to the `ds` tenant (see ticket 01)
- A published test course with at least two modules

## Steps

1. Open a course from the catalogue.
2. Look at all four tabs: **Übersicht**, **Experten/Referenten**,
   **Zertifizierung**, **Mediathek**.
3. On **Übersicht**: go through the module list. Can you tell which Kapitel
   belong to which Modul?
4. On **Zertifizierung**: what must be done to earn the points? Is that stated
   completely?
5. Start the course.
6. Go back to the overview without watching anything. Does progress read 0 %?
7. Copy the address from the address bar and open it in a new tab. Do you land
   in the same place?

## Expected

- Step 3: Kapitel are visibly **subordinate to a Modul** — not a flat list of
  equals.
- Step 4 names the conditions: video content watched, Lernerfolgskontrolle,
  Evaluationsbogen, EFN.
- Step 7 lands in the same place, not on the start page.

## Pay particular attention to

- **The module numbers.** Does the number in the sidebar match the number above
  the content? Please photograph both together.
- Locked content: can you tell **why** something is locked and what to do about
  it?

## Please report with

A screenshot of the module overview, and if the Kapitel grouping is unclear, one
sentence on what was missing.
